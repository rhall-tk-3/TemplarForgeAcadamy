Program Purpose

The Sergeant First Class course picks up where the Sergeant program ended. It carries the student from the fall and legacy of the medieval Templars into modern organizations, leadership development, spiritual identity, and preparation for the Knight Aspirant course. It also addresses the distinction between true Templar virtue and Masonic Templar structures, while stressing truth, charity, humility, discipline, and service-centered leadership.

Sources: SFC Lesson Plan, Britannica: Templars, Britannica: Freemasonry Facts, York Rite, OSMTH.

Week-by-Week Path

Each week reinforces history, discernment, leadership, and preparation for the next stage of formation.

From Sergeant to Sergeant First Class

Week 1 reviews the true historical Templars and introduces the Sergeant First Class rank as a step into more visible leadership, mature judgment, and preparation for Knight Aspirant.
