Schoolmaster Resources

Staff-facing tools for running the Squire School 8-week program — reading log review, lesson plans, attendance, oral review rubrics, and advancement materials.

Reading Log Review: The Student Reading Log is the primary record of student participation. Schoolmasters must review and initial each week's log row at the close of each class session. All four reading stacks must be initialed complete before the student is eligible for oral board review.
