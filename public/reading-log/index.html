✦ How It Works

  1. Select your active program from the dropdown above.
  2. Click any document link to open it — your open count is tracked automatically.
  3. Set the status for each document: Not started, In progress, or Completed.
  4. Add custom sources (books, articles, websites) to any week using the Custom Sources section.
  5. Use Submit to Schoolmaster to send your current progress directly to the SM dashboard — one click, no file needed.
  6. Use Export JSON to download a local backup of your log at any time.
  7. Progress is always saved locally in this browser first; Submit syncs it to the server.
