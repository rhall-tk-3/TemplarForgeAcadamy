Operational deployment checklist

1. Unzip repository
2. Run: npm install
3. Run: npm test
4. Run: npm run verify:deploy
5. Run: npm run smoke
6. Run locally: npm start
7. Open: http://localhost:3000
8. Confirm these endpoints:
   - /api/health
   - /api/curriculum
   - /api/resources
9. Confirm shared downloads open:
   - /resources/core-documents/18-Curriculum-Handbook.pdf
   - /resources/schoolmaster-forms/26-Fillable-Attendance-Sheets.pdf
10. Deploy options included:
   - Render: render.yaml
   - Docker: Dockerfile
   - Procfile-compatible hosts: Procfile
