# Curriculum Config

`index.json` is the canonical curriculum manifest used by the API and public repository build.

Each program entry defines core metadata such as:
- `slug`
- `title`
- `phase`
- `siteEntry`
- `audience`
- `durationWeeks`
- `programType`
- `hasReadingLog`
- `hasSyllabus`
- `hasLessonPlan`
- `navAliases`
- `sharedResourceKeys`
- `resources`
